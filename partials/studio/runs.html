How a project runs

Audit, build, go live, hand off.

Small, measured, and nothing changes on a live system without your OK.

AUDIT

Audit

Two sessions. I search for you, call you as a customer, try to book, and map your tools. You get a ranked plan and a fixed price.

BUILD

Build

The features you picked get built in accounts you own. Anything automatic gets a log, a limit and an off switch.

GO LIVE

Go live

Real customers use it while you watch. When something is off, I fix it and test the fix before it ships.

HAND OFF

Hand off

A one-page guide: what it does, where it lives, how to change it. Then we check off every feature together.
